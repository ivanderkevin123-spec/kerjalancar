# KerjaLancar

WhatsApp-first lead, quotation, follow-up, and payment tracking for Indonesian service businesses.

**Status:** Phase A (Discovery), validation week 2026-10-12 → 10-18. No product code yet. Start with `docs/PROJECT_STATUS.md`.

| Document | Purpose |
|---|---|
| `docs/PRODUCT_BRIEF.md` | Hypothesis, target customer, why alternatives may fall short, segments, MVP scope, exclusions |
| `docs/VALIDATION_PLAN.md` | 7-day plan, methods, Gate G1 thresholds (proceed / narrow / revise / extend / pivot / stop), pilot metrics |
| `docs/DAY1_EXECUTION.md` | Day 1 checklist: prospects, outreach message, scheduling, note-taking, follow-up |
| `docs/INTERVIEW_GUIDE.md` | 20–30 minute interview script (Bahasa Indonesia), note template, scoring rubric |
| `docs/CONCIERGE_TEST.md` | Spreadsheet-based concierge experiment: steps, metrics, limitations, privacy |
| `docs/COMPETITOR_RESEARCH.md` | Research checklist, verified findings, manual verification tasks |
| `docs/ASSUMPTION_REGISTER.md` | Assumptions with status and tests |
| `docs/RISK_REGISTER.md` | Risks and mitigations |
| `docs/ARCHITECTURE.md` | Go + HTMX vs Next.js decision, diagram, components, tenancy, money, security |
| `docs/ROADMAP.md` | 8-week plan, acceptance criteria, gates, traceability |
| `docs/DECISIONS.md` | Decision log with approval status |
| `docs/templates/` | `prospects.csv` and concierge sheet CSVs (copy into private Google Sheets) |

Private research data (interview notes, prospect lists with contact details, concierge sheets) lives in `docs/interviews/` and `docs/private/`, which are git-ignored.
